# 内部创新项目：IKEA AI 智能图像工作台 (MOSS)
— *从“图像修改工具”到“企业知识沉淀与赋能平台”*

## 1. Executive Summary (执行摘要)
在传统业务流程中，图像处理与高管宣推的图片素材面临着“高度依赖外部供应商（外包）、按次计费昂贵、沟通修改周期极长”的痛点。

本项目（代号：MOSS）旨在打破这一僵局。它不仅是一个提供“商品替换、场景微调”的工具，更是一个基于 **Vibe Coding (自然语言交互)** 和 **Node-based UI (节点化操作)** 的企业级数字资产赋能平台。MOSS 让产品、运营、门店导购等所有非视觉设计的业务全员，都能“零门槛”产出专业级素材，实现极致的降本增效，践行 IKEA “气候积极 (Climate Positive)” ESG 战略，并推动全组织内部“业务即研发”的敏捷创新文化。

---

## 2. 核心痛点 (Pain Points)

*   **流程重、依赖度高**：图片中指定位置添加或替换商品（如同款换色、异款替换）和物品移动，目前高度依赖外部设计公司或内部专业设计师。
*   **成本高昂（资金与时间）**：外部按数量计费且修图耗时长，如果存在失误或变更，必须发回重做，沟通扯皮成本高，A/B 测试成本难以承受。
*   **专业门槛高**：PS 等专业软件有复杂的快捷键和图层操作逻辑，即便是当前的生成式 AI，撰写高质量的 Prompt 依然存在较高门槛。
*   **经验难以复用与沉淀**：专业设计师在处理一张爆款海报或展间的思绪过程和工作流（Workflow），仅留存在他们个人电脑里，无法成为全公司复用的资产。

---

## 3. 什么是 MOSS？(Solution & How it Works)

MOSS 是以 **“Vibe Coding + Node-based UI”** 构建的新一代工作台。目前已经跑通了一系列基于前沿图像大模型（AIGC）的业务操作，并形成完整的闭环体系。

### 3.1 核心交互：将“复杂”降维至“本能”
*   **纯自然语言对话（右侧控制台）**：完全摒弃快捷键和复杂的提示词组合。通过右侧对话框，用自然语言即可发出命令（例如：“把图里的沙发换成深蓝色的 KIPPAN 沙发”，“把左边的花盆移到桌子上”或使用快捷按钮）。
*   **可视化节点管理（中央工作区）**：所有图像素材（左侧项目列表管理）都会显示在中央画板。**核心创新在于：每一次修改操作都会以上下相连的节点 (Node) 形式保存。** 
    *   **无损试错**：失误无需重做，可随时回退到上几步状态。
    *   **极速 A/B 测试**：可在任何一个节点拉出分支，快速验证不同的修改想法。

### 3.2 不仅是“工具”，更是“工作流容器”
*   **动作记录与反哺**：通过记录并分析设计师在节点中的操作思路，反向用于训练和微调未来的 AI 模型。
*   **一键复用**：复杂且成功的操作流程，可直接保存并在需要相似处理（如批量修改）的图片上进行大规模部署和大规模复用。专业人士也无需在 PS、3D 建模等多个软件间反复横跳。

## 4. 核心商业价值 (Core Business Value)

### 4.1 财务与效率的双赢 (降本增效)
*   告别高昂的外部供应商外包费用，将原本数周的沟通流程缩减至单次“自然语言对话即时产出”。

### 4.2 赋能线下，千店千面与互动促单
*   **本地化营销**：赋能门店运营（区域团队）直接调取总部素材，使用一句话进行本地化适应性修改（例如添加本地节庆元素、适应本地气候的背景），实现“千店千面”的敏捷营销。
*   **导购逼单神器**：门店终端导购可以使用该工具直接向客户展示特定样板间沙发的“实时换色效果”，无需等待效果图，直接促进转化。

### 4.3 虚实链路打通，践行 ESG 战略
*   **门店虚拟打样**：为设计师提供“零成本虚拟实验室”。物理搭建真实展间 (Roomset) 前，用 AI 快速替换商品、验证视觉灵感，避免物料浪费、降低实物搬运损耗，完美契合 IKEA “气候积极”的长期战略。

### 4.4 组织文化进化 (创新与引流)
*   **Vibe Coding 敏捷共创**：工具的开发本身对写代码能力要求不高。这就意味着，商业化、运营、产品人员也能根据自身思路直接向工具内“添加自己想要的功能”，打破“提需求->等工单->等排期”的漫长官僚周期。
*   **“AI 孤岛”流量聚合舱**：成为 Engineer（研发）部门推广 AI 的超级前端入口（Demo/Showcase）。公司内其他没有前端页面的 AI 算法（如下文将提及的“基于图像识别生成卖点插件”），均可统一挂载到 MOSS 面板上。构建成功后，可向 IKEA Global 汇报，极大提升本地技术团队的全球影响力。

## 5. 项目落地演进路线图 (Roadmap)

我们采取脚踏实地、逻辑严密的落地计划，确保快速交付价值：

*   **Phase 1: MVP 跑通与降本验证 (Now)**
    *   上线 Vibe Coding 界面和 Node-based UI，跑通商品替换、删除、移动。
    *   通过实际支持特定门店海报本地化和展间轻量化虚拟打样，**优先量化并锁定相比外包的“时间和资金双重节省”。**
*   **Phase 2: 核心壁垒深化与生态聚合 (Next)**
    *   **版权防守与品牌壁垒**：攻坚并内嵌“宜家真实 SKU 精准识别(>95%)”算法，确保每次生成的图像都严格使用宜家在售商品，规避品牌合规及外部版权风险。
    *   **动态与内容延伸**：接入“图生视频”能力，一键将修改好的空间图转化为适合 TikTok/Red/IG 传播的动态短视频。
    *   **建立插件分发系统**：正式开始整合图片描述、卖点生成等多部门算法能力。
*   **Phase 3: 系统级大动脉贯通 (Future Vision)**
    *   接入宜家全球业务大动脉：与宜家数字资产管理系统 (DAM) 对接，将修改过的数字资产通过智能自动化打标（基于识别能力解析出的风格、色系、SKU）安全沉淀入库。
    *   全球化标杆 (Global Showcase)：将验证无误的高效平台、减排 ESG 成果向 IKEA Global 全面汇报输出。

## 6. 核心干系人管理与常见 QA (Stakeholder Matrix)

为确保项目推进顺利，我们预先对各管理层的核心顾虑准备了清晰的规划保障：

**Q1：该工具会让内部设计团队面临裁员风险吗？（Online Commercial/Design Lead 顾虑）**
> **A:** 工具替代的是无创造力的“外包修图及抠图换色等低端机械劳动”。对于内部核心设计团队，它更是一个“减负工具”和“沉淀优质资产的杠杆”，能让人才释放精力去专注视觉定义的顶层设计，且 MOSS 专精于宜家内部商品替换，符合并维护 Brand Guidelines。

**Q2：业务自行用自然语言增加应用能力（Vibe Coding），会导致变成失控的影子 IT 吗？（Digital Manager 顾虑）**
> **A:** 架构上，底层 API（合规算法组件层）、数据链路和鉴权依然由 IT 部门实行集权管控。业务团队只是在“上层应用交互层”使用预制 API 像搭乐高一样构建自己的 Workflow。这种由 IT 守住底线、业务赋能高线的“权责分离”，未来也将在接入 DAM 系统的安全合规层通过。

**Q3：门店员工很忙，上线这个新系统需要学习成本吗？（Store/Regional Manager 顾虑）**
> **A:** MOSS 的最大特点就是“抛弃了软件逻辑”，学习门槛等于零。不需要背快捷键和写复杂 Prompt，纯直觉的自然输入。不仅不给一线添乱，甚至因为其展示的高效，可以成为前线导购在物理门店促单成单的额外武器。
